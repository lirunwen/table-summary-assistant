表格汇总助手 · 一页速查
==========================

一、打开与退出
  第一次：解压后双击「安装.bat」→ 桌面与开始菜单各生成一个图标 →
          以后双击桌面「表格汇总助手」图标即可。
          不想建图标，就直接双击「启动.bat」。
  打开后：浏览器会自动进入工作台；没有自动打开就输入 http://127.0.0.1:9090
  退出：  页面左侧栏底部的「退出应用」，确认后服务停止、黑色窗口自动关闭。
          不想用按钮，也可以直接关掉那个黑色窗口。
          只关浏览器标签页不算退出，服务还在后台跑。

二、七步完成一次汇总
  第 0 步  先定模板（可选，但推荐）
    打开「数据模板」→「新建模板」，一行写一个列名（如 员工编号、姓名、部门）。
    建好后到编辑页补：类型、必填、校验规则（不允许重复 / 只允许这些值 / 手机号格式…）。
    已经有现成的 Excel 表头？点「上传 Excel」直接读，字段会自动生成。
    模板只是“表长什么样”的约定，不涉及数据从哪来；同一份模板可以被多个方案复用。
    改字段会自动留一个版本，改错了可以回滚；被方案用着的模板默认删不掉，防止误删。

  第 1 步  上传文件
    打开「数据源」→ 把 Excel、CSV 或 Outlook 邮件拖进来。
    邮件正文里的表格和附件会自动展开。
    点「眼睛」图标预览，确认表头行是否正确（大标题占一行时，表头往往在第 2 行）。

  第 2 步  新建方案
    打开「汇总方案」→「新建方案」。
    填一个看得懂的名字，例如“10 月人员信息汇总”。
    人员、订单类汇总选「主表关联补齐」；
    多个月份/部门的同结构表选「多表纵向合并」。

  第 3 步  选主表、主键和关联表（方案里的第 1 段「数据来源」）
    主表：决定最后有多少行，通常是人名/订单最全的那张。
    主键：两张表都对得上的列，例如“工号”。
    关联表：补字段的表，不会增加行数。
    例：员工主表的“工号”对应考勤表的“员工编号”。
    选完主表和关联表，程序会立刻按列名把目标列的来源预匹配好，不用一列列手选。

  第 4 步  选目标模板（方案里的第 2 段「目标表」）
    在「目标表」选择第 0 步建好的模板（也可以在这里上传一份新的 Excel）。
    模板只决定表长什么样：表头、列宽、格式、公式列都沿用它，里面的示例数据不参与计算。
    行永远是当月数据表来的，模板不会往外吐数据。
    目标列明细默认是收起的，只显示列数、纳入数、必填数和列名概要；
    要改名、勾选或改类型，点右上角「目标列详情」展开。
    换模板、同步字段或切换到别的步骤后会自动收起，避免以为没生效。
    如果模板建完后字段又改过，这里会出现「模板字段有变化」，点「一键同步字段」即可；
    名字没变的列映射会保留，只把新增/删除的列对齐；只是取消勾选的列不算差异。
    覆盖：清掉模板旧数据再填；追加：接在已有数据后面。

  第 5 步  核对每一列来源（方案里的第 3 段「字段映射」）
    打开这一段时列已经配好了，直接逐行核对就行。
    机器配的列会挂一个小标签：「自动 · 同名」或「自动 · 备注名」；
    靠括号备注名命中的还会多一行「括号备注名「税前」」的说明。
    你手动改过哪一列，那个「自动」标签就消失——一眼能看出哪些还需要你确认。
    想重新跑一遍，点「按列名匹配」（这个会按列名把所有列重配一遍）。
    匹配分三层，优先级从高到低：
      同名      忽略大小写、空格、下划线、全角半角的写法差异都算同名，
                “员工_工号”“员工 工号”“EmployeeID”“employee_id”都能对上；
      备注名    拿模板列名括号里的字去对，“月薪（税前）”对数据表的“税前”；
      相似      差一点也对上，“手机号”对“手机号码”、“所属部门”对“部门”，
                这类会在状态标签上标出相似百分比，请你顺手核一下。
    状态标签会写明这一列是怎么配上的：同名 / 备注名 / 相似 93% / 手动。
    手动改过之后就变成「手动」，一眼看得出哪些还需要你确认。

    每一行只占一行，右边三个按钮：
      映射  弹层里改来源列、加备用来源、设取值方式、处理方式、缺省值、写公式；
            没匹配上的列，弹层里会按相似度列出候选，直接挑一个即可。
      清空  把这一列的来源清掉（自动匹配不会再填回来）。
      规则  看这一列在模板里的校验要求（必填、只允许哪些值、格式、长度）。

    行里的「取值」下拉管的是“同一个人匹配到多条记录”时怎么办：
      取第一个非空值  按来源顺序，第一个有值的胜出（默认）
      求和 / 计数     把多条加起来 / 数一共几条（加班合计、就诊次数）
      最大值 / 最小值 这一列自己取最大 / 最小（最早入职日期）
      取最新一条      按日期列找到最新那条，取那条记录里的别的列，要选排序列
      拼接            几个值用顿号连起来，重复的只留一次（参与过的岗位）

    某一列需要算出来（总额=单价×数量、全名=姓&名、大额判断）时，
    点这一行的「映射」→ 「写公式」：字段用方括号，如 =[单价]*[数量]。
    弹窗里能选函数、点字段名插入，还会用前 5 行真数据试算给你看。
    算不出来的格子会写成 #DIV/0! 这类 Excel 错误值，想兜底就套一层
    IFERROR，例如 =IFERROR([金额]/[数量],0)。

    日期列在「映射」弹层里可以选显示格式（「2026年10月21日」
    「2026-10-21」「2026-10」等 9 种）；默认跟随全局设置。
    写进 Excel 的仍是真日期，排序和日期计算都正常。

  第 6 步  预览、生成、下载
    点「预览前 50 行」，看行数、空值、列名。
    弹窗上方有「列完成度」：哪一列还空着、空了几格、必填列缺了没有，一眼能看出来。
    没问题再点「生成汇总表」。
    在结果弹窗点「下载结果」；以后也可以在「生成记录」里重新下载。
    需要核对上期数据时，到「数据对比」选两次结果和主键，导出差异报告。

三、最常用的几个词
  数据模板    定义目标表有哪些列、什么类型、什么规则（不管数据从哪来）
  数据源      上传的原始文件
  主表        决定最后有多少行的那张表
  主键        用来对上号的列，如工号、订单号
  关联表      给主表补字段的表
  目标表      最后要填的那张 Excel
  缺省值      找不到数据时默认填什么
  固定值      整列都写同一个内容
  覆盖/追加   清空旧数据再填 / 接在已有数据后面

四、数据在哪里
  程序目录下的 data 文件夹。
    data/library   上传的文件、邮件正文、附件
    data/templates 数据模板（Excel 文件，一个模板一个文件夹）
    data/runs      每次生成的结果
    data/compares  对比报告
  备份时整个复制 data；升级程序时保留 data，不要删除。

五、常见问题
  1. 关联表大量空白：检查主键有没有空格、文本/数字格式是否一致、
     工号是否重复。工号列建议用「去除首尾空格」。
  2. 生成后有空列：到「字段映射」看这一列有没有变绿，来源字段和缺省值是否选对。
  3. 模板列错位：检查模板的“表头行”是否选对，点「调整」重新读取。
  4. 图表/图片/透视表不见了：当前写入方式可能无法完整保留这些对象，
     重要模板请生成后人工核对。
  5. .pst 邮件：暂不支持，请在 Outlook 里另存为 .msg。
  6. 页面打不开：确认黑色启动窗口还开着，访问 http://127.0.0.1:9090。
  7. 数据会丢吗：关闭窗口不会丢，数据在 data 文件夹；
     重要结果请下载到自己的业务文件夹，工具只保留最近 30 条生成记录。
  8. 表格里有 #DIV/0! / #VALUE!：公式没算出来。看到生成结果里的警告会写明
     哪一列、多少行、第一个错在第几行；把公式改成 IFERROR(原公式,0) 即可兜底。
  9. 模板校验报了问题但表还是生成了：校验只提示不阻断，警告清单会写清
     第几行、哪一列、什么原因，按提示改完再生成一次即可。
 10. 桌面图标变成白色 / 双击没反应：文件夹被搬过。到新位置再双击一次
     「安装.bat」，或在「设置 → 快捷方式与退出」里点「创建快捷方式」。
 11. 一个人有多条记录，结果只拿到一条：到「字段映射」把这一列的「取值」
     从「取第一个非空值」改成求和 / 计数 / 取最新一条。要最新的那条记录里的
     别的列（比如最近一次就诊的医院），选「取最新一条」并指定按哪一列排序。
 12. 想看哪一列还没填上：点「预览」，弹窗上方「列完成度」按空的多少排序，
     必填列缺值会标红；那一列的来源、缺省值再对一遍即可。
 13. 打开方案发现列都配好了：那是自动按列名预匹配的，机器配的列带「同名 / 备注名 /
     相似 xx%」标签。觉得配错了就点那一行的「映射」改，改完标签就变成「手动」；
     想整体重跑一次点「按列名匹配」。
 14. 想看模板到底有哪些列：第 2 步「目标表」里点右上角「目标列详情」展开，
     不展开时只显示列数与必填数。
 15. 按列名匹配一个都没中：多半是写法差异（大小写、空格、下划线、全角）。
     现在这些都算同名；实在对不上的，状态标签会标「相似 xx%」，
     或者点该行的「映射」从候选里挑。

六、找谁帮忙
  遇到解决不了的问题，截图 + 说明在第几步 + 文件名/工作表名 + 错误提示，
  发给信息管理员，能最快定位。
